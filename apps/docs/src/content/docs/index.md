Rainrail connects provider events, workflow routing, and agent execution into a
small set of observable contracts. These docs are the durable home for setup,
concepts, operational procedures, and API references.

## Sections

- [Quickstart](/quickstart/) introduces the shortest path to a local build.
- [Concepts](/concepts/) explains the event and workflow boundaries.
- [Guides](/guides/) collects task-focused implementation notes.
- [Reference](/reference/) records contracts and command surfaces.
- [Operations](/operations/) covers deployment and production checks.
